# Бриф: главная страница мастерской кожаных изделий

## Клиент
Мастер (женщина) шьёт вручную изделия из натуральной кожи: сумки, кошельки, брелки. Беларусь, цены в BYN. Сайта нет. Референс, который ей нравится: https://belski-hm.by/ (тёплая мастерская, каталог, «оформить по телефону»). Наша задача – сделать заметно современнее и удобнее референса.

Задача сайта: продавать + привлекать заявки + презентовать мастерскую. Интеграций нет (заказ = заявка мастеру, без онлайн-оплаты).

## Что обязательно должно быть на главной
1. Шапка: логотип, меню (Каталог, В наличии, Под заказ, О мастерской, Доставка и оплата, Контакты), иконка корзины со счётчиком
2. Первый экран: кто мы и что делаем, две кнопки – «Смотреть каталог» и «Заказать своё изделие»
3. Категории: Сумки, Кошельки, Брелки
4. КЛЮЧЕВОЕ разделение на два пути: «В наличии» (готовые изделия, отправим за 1–2 дня) и «Под заказ» (сошьём по вашим пожеланиям: цвет кожи, цвет нити, гравировка, срок 7–14 дней)
5. Каталог-витрина: карточки товаров с фото, названием, ценой, статусом («В наличии» / «Под заказ») и кнопкой «В корзину» (для «под заказ» – «Заказать»). Карточка должна поддерживать бейдж «Акция» и старую цену, но сейчас акций НЕТ – ни одного бейджа акции и блока акций не показываем (в CSS класс `.is-sale` заложить, в разметке не использовать)
6. Как заказать изделие под заказ: 4 шага (Выбираете модель или присылаете идею → Согласуем кожу, нить, гравировку и цену → Шьём вручную 7–14 дней, присылаем фото → Доставляем)
7. О мастерской: короткий тёплый текст от первого лица мастера + фото процесса. Без выдуманных цифр (никаких «10 лет опыта», «5000 клиентов»)
8. Доставка и оплата: Европочта и Белпочта по Беларуси, курьер/самовывоз – уточняется; оплата при получении или переводом. Коротко, карточками
9. Финальный призыв + форма/кнопка заявки (имя, телефон или Telegram/Instagram, что хотите сшить) – форма без реальной отправки, по submit показать «Спасибо, мастер свяжется с вами»
10. Подвал: меню, контакты-заглушки (+375 (00) 000-00-00, @instagram), копирайт

Чего НЕ делать: отзывы, блог, счётчики-достижения, блок акций, выдуманные факты о мастере.

## Бренд
Названия пока нет. Рабочее имя-заглушка задаётся в `js/brand.js`. В разметке НЕ писать название текстом: использовать `<span data-brand></span>` (подставится «ШОВ»), для слогана `<span data-brand-tagline></span>`. В `<title>` писать «Мастерская кожаных изделий – вариант A/B/C».

Подключить в конце body (обязательно, в таком порядке):
```html
<script src="js/brand.js"></script>
<script src="js/switcher.js"></script>
```
`switcher.js` сам рисует внизу экрана маленький переключатель вариантов A/B/C – не перекрывайте правый нижний угол своими фиксированными элементами (оставьте 64px снизу справа).

## Правила текста (строго)
- Русский язык, простые живые слова, без жаргона и канцелярита
- Длинное тире «—» ЗАПРЕЩЕНО, только короткое «–»
- Заголовки, пункты списков, подписи кнопок – без точки в конце
- Цены – заглушки в BYN, формат «140 BYN»

## Техника
- Чистый HTML + CSS + ванильный JS, без сборки. Файлы варианта: `{x}.html`, `css/{x}.css`, `js/{x}.js` (x = a | b | c). Чужие файлы не трогать
- Шрифты – Google Fonts, ОБЯЗАТЕЛЬНО с кириллицей (проверьте subset=cyrillic). Inter, Roboto, Arial, Montserrat – запрещены
- Адаптив: 1440, 1024, 768, 390. На 390 – никакого горизонтального скролла страницы, бургер-меню работает
- Корзина: клик «В корзину» увеличивает счётчик в шапке и даёт короткую обратную связь (без страницы корзины)
- `prefers-reduced-motion`: анимации отключаются/упрощаются, включая canvas/WebGL-цикл
- Контраст текста не ниже 4.5:1, видимый focus, кнопки – настоящие `<button>`/`<a>`
- Сторонние библиотеки только с cdnjs.cloudflare.com или cdn.jsdelivr.net, и только если реально нужны

## GetLayers (обязательно использовать)
Инструменты MCP GetLayers отложенные: загрузите их через ToolSearch запросом `getlayers` (max_results 15). Порядок:
1. `getlayers_start` – прочитать гайд, особенно `revealChoreography` и правила композиций
2. `getlayers_compositions` с role (`hero`, `card-grid`, `editorial`, `cta`, `footer` и т.д.) – ПЕРЕД вёрсткой каждой крупной секции выбрать скелет композиции и следовать ему. Никаких «всё по центру стопкой»
3. `getlayers_materialize` – ТОЛЬКО для того ассета, что назван в вашем задании, с `target: "other"`. Лимит строгий, не материализуйте лишнего. Цвет шейдера менять ТОЛЬКО через его CONFIG (цвета #rrggbb), GLSL не трогать
4. Медиа с storage.getlayers.ai не хотлинковать. Шейдер-градиент – самодостаточный код, его встраиваем в страницу (canvas позади контента, `pointer-events` по ситуации, lazy-mount, пауза вне вьюпорта и при reduced motion)
5. В конце записать `docs/getlayers-{x}.json`: какие композиции и ассеты использованы в каких секциях

## Проверка перед сдачей (обязательно)
Снять скриншоты Playwright (Python, `from playwright.sync_api import sync_playwright`, chromium) по `file:///D:/MYDEV/leather-prototype/{x}.html`: полный 1440 и полный 390, сохранить в `docs/screens/{x}-1440.jpg` и `{x}-390.jpg` (jpeg quality 70). ПОСМОТРЕТЬ их через Read и исправить всё кривое: наложения, пустые картинки, обрезанный текст, горизонтальный скролл (`document.documentElement.scrollWidth <= innerWidth`), ошибки консоли. Python-скрипты писать в файл (`tools/shot_{x}.py`), не через heredoc – на Windows heredoc портит кириллицу. Для элементов с reveal-анимацией по скроллу перед полным скриншотом прокрутить страницу до низа шагами, иначе секции будут пустыми.
