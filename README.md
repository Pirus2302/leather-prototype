# Мастерская кожаных изделий, прототип главной

Три варианта главной страницы для мастера, которая шьёт сумки, кошельки и брелки из кожи (Беларусь, BYN).

- `index.html` – обложка с выбором варианта
- `a.html` – A «Красивая и современная»: светлая журнальная вёрстка
- `b.html` – B «Удобная и креативная»: бенто, фильтры каталога, конструктор своего изделия
- `c.html` – C «WOW»: тёмная страница, нить прошивает сайт по мере прокрутки

Общее: `js/brand.js` – название-заглушка (меняется в одном месте), `js/switcher.js` – переключатель вариантов для показа клиенту, `docs/brief.md` – бриф и правила.

Заглушки: название «ШОВ», цены, фотографии (Unsplash, свободная лицензия, подключены ссылками).

GetLayers: шейдер-градиенты `charmeuse` (A), `chatoyance` (B), `drape` (C) и композиции секций – учёт в `docs/getlayers-{a,b,c}.json`.

## Проверки
Нужны Python 3.11, `pip install playwright`, `playwright install chromium`.

    python tools/shot_a.py
    python tools/shot_b.py
    python tools/shot_c.py
    python tools/covers.py    # обложки для index.html, нужен локальный сервер на 3121

## Локальный просмотр
    python -m http.server 3121
